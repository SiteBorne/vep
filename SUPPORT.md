# Support

VEP is pre-release software (published prerelease `0.4.0a1`; beta `0.5.0b1` published, `0.6.0b1` release candidate unreleased), maintained on a best-effort basis.

* **Questions and usage help:** open a [GitHub issue](https://github.com/SiteBorne/vep/issues) (GitHub Issues is enabled for this repository; GitHub Discussions is currently disabled, checked 2026-10-19, so it is not offered as a channel).
* **Bugs:** open an issue with `vep version --json`, your OS/Python version, the exact command and output.
* **Security problems:** never in public — see [SECURITY.md](SECURITY.md).
* **Before asking:** read [docs/QUICKSTART.md](docs/QUICKSTART.md) and the limits in [docs/SECURITY_ARCHITECTURE.md](docs/SECURITY_ARCHITECTURE.md).

No service-level agreement is offered.
