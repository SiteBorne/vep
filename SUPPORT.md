# Support

VEP 0.4.0a1 is a developer preview maintained on a best-effort basis.

* **Questions and usage help:** open a GitHub Discussion or issue on the project repository (maintainers: enable Discussions, or point this section to the preferred channel — **CONFIGURATION REQUIRED**, no channel is invented here).
* **Bugs:** open an issue with `vep version --json`, your OS/Python version, the exact command and output.
* **Security problems:** never in public — see [SECURITY.md](SECURITY.md).
* **Before asking:** read [docs/QUICKSTART.md](docs/QUICKSTART.md) and the limits in [docs/SECURITY_ARCHITECTURE.md](docs/SECURITY_ARCHITECTURE.md).

No service-level agreement is offered.
