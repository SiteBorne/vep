# Security Review — 0.4.0a1

Scope: code-level review of the 0.3.0 → 0.4.0a1 tree (all of `src/vep`, scripts, workflows, packaging). Method: reading the code paths named in the review checklist, targeted attack tests, `grep`/AST guards for dangerous primitives, and the release scanners. Reviewer: the release engineer (an AI assistant working with the maintainer); this is **not** an independent third-party audit.

Severity scale: CRITICAL (host or authority compromise without operator consent), HIGH (breaks a core guarantee given a plausible precondition), MEDIUM, LOW, INFO. Status: FIXED, MITIGATED (risk reduced, not removed), ACCEPTED_RESIDUAL (documented limitation), NOT_APPLICABLE. Every FIXED/MITIGATED finding names an existing regression test; the release gate enforces this.

## Review checklist coverage

1. Signing-key generation/storage — SR-01, SR-02 (Ed25519 via `cryptography`, `O_EXCL` creation, 0600, permission refusal on load).
2. Filesystem permissions — SR-02.
3. Secret exposure through exceptions/logs — error messages carry ids and paths only; CLI never prints key material (`tests/test_integration.py::CLITests.test_no_secret_material_is_printed`); stderr/stdout of evaluated code is stored in the CAS, so **do not evaluate code that prints secrets**.
4. Temporary directories — `tempfile.mkdtemp` (0700), removed in `finally` after making files writable.
5–6. Shell/subprocess arguments — SR-14.
7. Environment inheritance — SR-17.
8. Import paths — SR-08, runner append-only `sys.path`, `python -I`.
9. SQLite transactions — `BEGIN IMMEDIATE`, rollback on any exception; concurrency tests.
10–11. Deserialization / canonical JSON — strict parser; no pickle/yaml (SR-14).
12. Symlinks — SR-04, SR-15.
13. Archive extraction — SR-16.
14. Candidate staging — read-only materialization from CAS in a fresh temp dir outside the workspace.
15. Protected suites — digest-pinned required tests, protected patterns, shadow-name denial.
16. Evidence trust — SR-01, SR-06, SR-07, SR-09.
17. Container configuration — SR-03 and the T1–T12 matrix; **unexecuted against a real runtime on the dev host**.
18. Dependency integrity — SR-18.
19. CI permissions — SR-10.
20. Release artifact contents — SR-11.

## Not reviewed / out of scope
Third-party dependency internals, the Docker/gVisor implementations, hosted GitHub behavior, and any real-runtime isolation result (none exists).
