# Formal Invariant Registry

Each invariant states a property that must hold for every execution, where it is **enforced structurally** (code, schema, DB trigger — not an instruction to an agent) and which test **demonstrates** it. A test references below are `file::Class.method` and are checked to exist by `tests/test_docs.py`.

## Invariants deliberately NOT provided

* Hostile-code containment (needs a real sandbox; see `THREAT_MODEL.md`).
* Report authenticity against a hostile candidate in trusted-local mode (the report writer shares a process with candidate code).
* Distributed-coordination invariants (leases across hosts, global merge ordering): local analogues only (`WorkClaim`, `compose`, CAS on versions).
